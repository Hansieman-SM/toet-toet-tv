Privacy policy – Toet uploader

"Toet uploader" is a private tool used only by the owner of the YouTube channel Toet Toet and Friends TV to manage the channel's own videos (sorting them into playlists and setting their language settings).

  • It accesses only the owner's own YouTube channel, through the YouTube Data API, with the owner's permission.
  • It does not collect, store, sell or share any personal data of viewers or other users.
  • Access tokens are stored only as encrypted secrets of the owner's own GitHub repository and can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: via the channel @ToetToetAndFriends.
