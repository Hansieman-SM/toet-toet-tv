# Learning series (approved by Hans 2026-11-08) – one learning video per day at 14:00 Europe/Amsterdam, YouTube only (16:9)
Rules: child-friendly, calm pace (±7 s per number, ±5 s per letter), no overkill. Alternate COUNTING and ABC day by day; about every 4th learning video is a "Can You Find It?" (slow question → 3-dot pause → answer). 
Each video: new scene file ep/learnNN_<slug>.js on lib/story.js (see ep/learn01_leaves.js), NEW music function in lib/audio2.py + kind in ep/mix.py, English thumbnail, SUBSCRIBE=1, QC. Counting = tray of 10 at the top + big numeral + number word + rising chime + recap 1–10. ABC = alphabet strip with current letter + letter block (upper+lower case) + object + word with coloured first letter + recap A–Z (see sb/learn_storyboard.js).
Mark a theme as used with date + job name. Seasonal: autumn until ±Nov 30, winter/December (Christmas with Santa, no Sinterklaas) after that.
